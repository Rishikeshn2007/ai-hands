ai-hands API

A secure REST API for news and weather. All endpoints require a Server-API-Key header.

Endpoints

GET / — This page (public)
GET /news/{topic} — Top news for a topic
GET /weather/{city} — Current weather for a city

Authentication

Add the key to every request header:

Server-API-Key: your-secret-key

Example

curl -H "Server-API-Key: your-key" http://localhost:8000/weather/London
